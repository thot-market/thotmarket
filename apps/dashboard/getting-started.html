Set up this computer once

The current helper is a developer preview, tested on Linux. It needs a project checkout, Node 24 or later, Python 3, and a reviewed dcap-qvl executable. Your demo operator supplies the checkout and hardware verifier. There is no automatic verifier download or Windows installer yet.

From your project checkout, run:

node scripts/install-capture-helper.ts --thot-url YOUR_THOT_URL

This installs three small commands in ~/.local/bin. Keep the checkout in place. If your shell says “command not found”, add that directory to PATH:

export PATH="$HOME/.local/bin:$PATH"

Capture with your usual coding tool

You need Codex or Claude Code already installed and signed in with your usual subscription. No model API key is required.

  1. Run thot-setup codex or thot-setup claude. Follow the first missing prerequisite it reports.
  2. From the project you want to capture, run thot-capture codex or thot-capture claude.
  3. Open the printed link in thot market and choose Start private capture. Allow local-network access if Chrome asks; this connects the website to your local helper.
  4. Return to your terminal and work normally. Exit the coding tool to save the capture. Keep thot market open to see the confirmation.

Your helper checks the recorder’s hardware proof before passing credentials. The vault checks the signed capture before saving it. Provider login is handled by your usual coding tool.

Connect real Robinhood

  1. Run thot-setup robinhood. This also checks Python’s account-verification dependencies.
  2. Run thot-link robinhood and open the printed link in the Chrome profile you use for Robinhood.
  3. Choose Check connection. Open or refresh Robinhood to thot the connector. If it still does not respond, expand the installation help; thot market shows the generated extension folder.
  4. Once Chrome is connected, open or refresh Robinhood. Your existing login carries over; sign in only if Robinhood itself asks.
  5. Return to thot market. Wait for Robinhood connected. The credential lasts 24 hours; use Renew Robinhood connection when it expires.

The first extension installation still uses Chrome’s developer mode. The Chrome installation steps are documented by Google. Chrome profiles with extension restrictions are not yet supported.

Python dependency is missing

For Robinhood, Python needs cryptography and certifi. Use an isolated environment in the project checkout:

python3 -m venv .venv
.venv/bin/python -m pip install cryptography certifi
export THOT_CAPTURE_PYTHON="$PWD/.venv/bin/python"

Rerun thot-setup robinhood. If the hardware verifier is missing, ask the demo operator for the reviewed executable. The helper will not disable that check.

If something stops

  • Helper unavailable: keep its terminal running and open its latest printed link. An old link expires.
  • Chrome permission denied: allow this thot market site to access the local network, then choose Try again.
  • Extension missing: enable it in the same Chrome profile as Robinhood. thot market advances only after the extension contacts the helper.
  • Waiting for an account request: refresh Robinhood after the extension is connected.
  • Verification failed: retry once, then share the short error code with the demo operator. Never paste a password or token.
