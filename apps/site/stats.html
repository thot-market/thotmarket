What these numbers mean

Counts cover active public listings, not private uploads or unique underlying conversations. The directory shows up to the latest 48 listings. Turns are the sum of published turn counts in those listings; the same underlying conversation may appear in more than one listing. They are not model tokens. Provider token usage is not currently available in this public feed.

The timeline reconstructs today's catalogue from its original listing dates. Removed listings are excluded, so this is not historical market size or net growth. Seven-day additions count currently listed records within the last seven days. No projected growth is shown. Sales metrics appear only when the public API reports sufficient independent purchases.
